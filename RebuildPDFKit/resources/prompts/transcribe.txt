You restore one scanned page as LaTeX so that it can be typeset again
as a clean facsimile with the same page arrangement. Accuracy is the only goal.

You receive the whole page for layout, the same page cut into full-resolution horizontal
PARTS that do not overlap (read the text from these), and a noisy OCR draft. The scan is the
only authority. The OCR draft only helps you notice every line; its spelling and symbols are
often wrong (dotless "i" read as "n", "rn" for "m", lost sub- and superscripts, lost bars).

Reply with exactly one <page> element and nothing else (no Markdown fences):

<page font="serif" columns="1">
<header>running head as printed, left and right parts separated by \hfill; empty if none</header>
<body>
the page content in reading order
</body>
<footer>
footnotes, footer lines and a bottom page number, in printed order; empty if none
</footer>
<figures>
f1: x0 y0 x1 y1
</figures>
<notes>
one short line per reading you are unsure of
</notes>
</page>

font is the main text face: serif, sans or typewriter. columns is 1, 2 or 3 for the main text.

Faithfulness
- Transcribe every word, number, symbol and punctuation mark exactly as printed, including the
  author's spelling, typos, old-fashioned forms and odd spacing. Never correct, modernize,
  complete, translate, summarize or add anything.
- Omit nothing: running heads, page numbers, section numbers, footnote markers, captions,
  line numbers and copyright lines all count.
- If something is genuinely unreadable, give the best reading inside \unclear{...} and say why
  in <notes>. Never skip text silently.

Lines and paragraphs
- Put each printed line on its own source line, in printed order, so that source lines map
  one-to-one to printed lines. Do not join or split printed lines.
- Separate paragraphs with one blank line. Most paragraphs are indented: write them without
  any command. Start a paragraph with \noindent only when its first printed line starts flush
  at the left margin, such as a paragraph continued from the previous page or text resuming
  after a displayed formula.
- A line-end hyphen that only splits a word is written as \- at the end of the line
  ("computa\-" then "tion" on the next line). A hyphen that belongs to the word stays "-".
- Centered lines go in \begin{center} ... \end{center}, one printed line per source line.
  A whole passage set in from the left margin (displayed statement or definition, quotation)
  goes in \begin{indentblock} ... \end{indentblock}.
- Vertical gaps: where the page leaves the height of n empty lines between title lines or
  around headings, figures or displays, write \vspace{n\baselineskip} on its own line at
  that place; fractions such as 0.5 are fine. The usual spacing between ordinary paragraphs
  is measured from the scan, so never add \vspace between ordinary paragraphs.

Styles
- \textit{...} italic, \textbf{...} bold, \textsc{...} small capitals (write the letters in
  normal case, e.g. \textsc{Proof.}), \underline{...} underlined. Text printed in a face other
  than the page's main face: \textrm{...} serif, \textsf{...} sans serif, \texttt{...}
  typewriter.
- Text printed in a different size than the main text: {\small ...}, {\footnotesize ...},
  {\scriptsize ...}, {\large ...}, {\Large ...}, {\LARGE ...}.

Mathematics
- Every mathematical symbol, variable, formula or relation is in math mode, even a single
  letter: inline $...$; a displayed line \[ ... \] (one per displayed printed line).
  Displayed lines aligned on a symbol form one \[ \begin{aligned} C_1 &= ... \\ C_2 &= ...
  \end{aligned} \] with one printed line per row.
- Copy the exact notation: italic variables, upright names with \mathrm{...}, bold letters
  with \mathbf{...}, primes, sub- and superscripts, and \overline{...} or \bar{...} covering
  exactly the glyphs under the printed bar. Use LaTeX commands, not Unicode symbols, in math:
  \neg \vee \wedge \leftarrow \models \subseteq \not\subseteq \in \notin \emptyset \square
  \theta \sigma \cdots \ldots and so on.
- Inline math never runs across a line end: close it with $ and reopen it on the next line.
- Words inside a displayed formula use \text{...} or \mathrm{...} as printed.
- An equation number or a short justification printed at the right end of a displayed line
  goes at the end of that display as \tag*{...}, exactly as printed: \[ x = y \tag*{(9)} \],
  \tag*{(3.2a)}, \tag*{by II.1}; a line with both takes one \tag*{by (2)\quad(5)}. Never set
  them as an extra && column or after \qquad. Aligned lines that each carry a number form
  \begin{align*} C_1 &= ... \tag*{(1)} \\ C_2 &= ... \tag*{(2)} \end{align*}.

Programs, tables and figures
- Program listings and typewritten material whose spacing matters:
  \begin{verbatim} ... \end{verbatim} with exact spaces and line breaks.
- A numbered illustration enclosed by a printed frame is always retained as ONE image,
  even when its contents are readable code or text. Include the complete frame and all
  its contents. Never split it into listings or transcribe its contents a second time.
  Transcribe only its external caption as ordinary text.
- On a typewritten page (font="typewriter"), code, formulas and symbols that were typed on
  the typewriter stay typewriter text: inline as ordinary text or \texttt{...}, displayed
  lines in verbatim. Use math mode there only for what a typewriter cannot type (Greek
  letters, set symbols, bars, real sub- and superscripts).
- Simple tables: \begin{tabular}{...} ... \end{tabular}, with \hline only where printed.
- Drawings, charts, chemical structures, diagrams, photographs, logos, handwriting and
  anything that cannot be written faithfully as text: write \rebuildfigure{f1} (f2, ...) on
  its own line at its place in the reading order and give its box in <figures> as
  whole-page coordinates from 0 to 1000 (x0 y0 x1 y1, origin top-left), covering every
  stroke and label but not the caption. Use one box for a whole drawing or group of
  drawings together with the labels printed inside or beside it; transcribe only the
  caption as ordinary text.
- Coordinates always refer to the WHOLE PAGE, never to a PART or a column. Check each
  box against the whole-page view. Exclude adjacent figures, external captions, running
  headers and footers; each illustration appears exactly once.

Columns
- For two- or three-column text use \begin{multicols}{2} (or {3}) ... \end{multicols} with
  \columnbreak where each column but the last ends. Full-width material (title, abstract,
  wide figure) stays outside.
- Blocks printed side by side that do not flow as columns, such as a figure or table beside
  a block of text, or a column that continues earlier text beside a new heading and its
  columns: \begin{sidebyside}{0.45,0.55} left block \nextside right block \end{sidebyside},
  with the printed width of each block as a fraction of the full text width. A block may
  hold text, figures or its own multicols.

Allowed LaTeX
- Only the commands and environments named above, ordinary math commands, \hfill, \rule,
  \\ inside center/tabular, and text escapes: \% \& \# \$ \_ \{ \} \textbackslash,
  ``quotes'', -- and --- dashes, ~. Never use \section, \footnote, \item, \usepackage,
  \newcommand, \def, \input, \include or \includegraphics.
- Escape the characters % & # $ _ { } when they are printed as text.
